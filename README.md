# Md. Shakil Khan — Professional Profile Website

A responsive, custom-coded personal profile website built with HTML, CSS, and JavaScript. Designed in navy blue, orange, and white for GitHub Pages hosting.

## Files

- `index.html` — page structure and profile content
- `styles.css` — responsive layout and styling
- `script.js` — mobile navigation, current year, and contact email behavior

## Before publishing

1. Open `script.js`.
2. Replace `your.email@example.com` with your real professional email address.
3. Review `index.html` and update any text that needs to be more specific to your experience.
4. Add verified employer names, job dates, technical skills, achievements, LinkedIn, or GitHub links only when you are ready. Do not publish confidential project details or sensitive government-system information.
5. If you want a real portrait, replace the initials-based placeholder in `index.html` with a photo you are comfortable sharing publicly.

## Preview locally

Open `index.html` in a web browser. No build tools or package installation are required.

## Publish with GitHub Pages

1. Sign in to GitHub.
2. Create a **public repository** named `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your exact GitHub username). This creates a user-site URL.
3. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root. Do not upload the ZIP file alone.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait for the Pages deployment to finish. Visit `https://YOUR-USERNAME.github.io/`.

If you already have a GitHub Pages repository or want this as a project site, you can use a repository named something like `shakil-profile`; its URL will be `https://YOUR-USERNAME.github.io/shakil-profile/` when configured for Pages.

## Notes

- GitHub Pages is suitable for this static HTML/CSS/JavaScript site and can be used at no hosting cost for a public repository.
- The contact section uses a `mailto:` link; it does not include a contact form or backend.
- The Google Fonts import requires an internet connection. System fonts remain as fallbacks if Google Fonts is unavailable.
- The website does not claim specific employers, certifications, awards, or measurable achievements that have not been supplied.
